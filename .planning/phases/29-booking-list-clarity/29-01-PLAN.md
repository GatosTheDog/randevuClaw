| Boundary | Description |
|----------|-------------|
| Telegram callback_data → findSessionInstanceById(businessId, instanceId) | instanceId ultimately originates from a Telegram callback_query.data string, which is fully attacker-controlled input (any Telegram user can send arbitrary callback_data, not only literal button taps) |
| Owner tooling → listSessions(businessId, limitDays, excludePastToday) | excludePastToday must never silently flip its default for owner-facing callers, or an owner permanently loses visibility into same-day past-time classes they still need to manage |
