<objective>
Expand the business owner's native Telegram (☰) command menu from 1 command (`/menu`) to 7 total — `/menu` plus 6 new commands, one per existing admin root-menu button (`showAdminRootMenu`'s 6-button keyboard) — each routed directly to that sub-menu, skipping the root menu entirely. This mirrors the exact pattern already shipped for the client side earlier today (quick task 260729-rjv: `/book`, `/mybookings`, `/cancel`, `/balance`).

Command set (mirrors showAdminRootMenu's 6 buttons, in the same order):
1. `settings` → Ρυθμίσεις → `showSettingsMenu(chatId, business)`
2. `classes` → Μαθήματα → `showClassesMenu(chatId, business)`
3. `clients` → Πελάτες → `showClientsList(chatId, business)`
4. `agenda` → Ατζέντα Σήμερα → `showTodaysAgenda(chatId, business)`
5. `payment` → Καταχώρηση Πληρωμής → `showClientSelection(business.id, chatId)` (different arg order — businessId first)
6. `invite` → Πρόσκληση Πελάτη → `handleInviteGeneration(chatId, business)`

Purpose: Make every admin sub-menu directly reachable via the native Telegram command list, matching the discoverability already delivered for clients.

Output: Both owner-scoped setMyCommands registration call sites register 7 commands; handleFoundBusiness's owner branch routes all 6 new commands directly; existing and new tests cover the change.
</objective>
