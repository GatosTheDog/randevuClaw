<objective>
Fix a silent scope bug in the 08:00 automated daily agenda push: `runAgendaSweep` in `src/scheduler/agenda.ts` calls `listBookingsForDate(businessId, todayIso)` without a third `statuses` argument, so it falls back to the function's default `['confirmed']` only — silently excluding `pending_owner_approval` bookings from the owner's auto-pushed agenda. The two other call sites in the codebase (`admin-menu.ts`'s `showTodaysAgenda` and `ai-owner-agent.ts`'s `view_todays_schedule` case) both correctly pass `['confirmed', 'pending_owner_approval']`. This plan makes the auto-push call site consistent with those two, and adds a regression test so the statuses filter can't silently regress again.

Purpose: Owners currently see a today's-agenda message at 08:00 that under-reports pending bookings awaiting their approval, creating a blind spot inconsistent with the on-demand `/agenda` command and the AI owner-agent's schedule view.
Output: `src/scheduler/agenda.ts` call site fixed; `tests/calendar-agenda-reminder-queries.test.ts` updated with an assertion that catches a regression of this exact bug.
</objective>
