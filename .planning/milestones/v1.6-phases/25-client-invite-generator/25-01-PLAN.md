<objective>
Give the business owner a one-tap way to generate a printable, self-contained client invite: a QR code with the business name and a Greek call-to-action baked into the image pixels, plus the raw `t.me/<bot_username>` deep link as copyable plain text in the same Telegram message — reachable both from the admin menu and from free Greek chat (INVITE-01).

Purpose: Onboarding a new client today requires the owner to manually explain how to find and start the bot. A single generated invite (QR to print/post, link to forward) removes that friction entirely, with zero backend cost beyond one Telegram API call and local image composition.
Output: A new `src/invites/generator.ts` module (QR generation via `qrcode`, text-into-pixels composition via `sharp`, per user decision — not `svg2png-wasm`/`@resvg/resvg-js`), a new `sendTelegramPhoto` export on the existing Telegram client, and two wired trigger points (admin menu button, `send_invite` AI-agent tool) that both call the same orchestration function.
</objective>
